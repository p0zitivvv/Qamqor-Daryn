# 🩺 Qamqor — Экспериментальная система кардиомониторинга

**Qamqor** — цифровая программно-аппаратная платформа для сбора и анализа физиологических показателей со смарт-браслета на базе микроконтроллера **ESP32**, оптического пульсоксиметра **MAX30102** и аналогового модуля ЭКГ **AD8232**.

Система реализует строгую математическую модель расчёта динамического индекса состояния ($0 \dots 100$) с нормализацией анкетных факторов, персональной калибровкой базовой линии (7 дней), фильтрацией артефактов RR-интервалов, дискретным EMA-сглаживанием и машиной состояний тревог с гистерезисом.

> **Важное уведомление:** Экспериментальный индекс Qamqor является исследовательской математической моделью и **не является валидированным клиническим диагнозом** или медицинской вероятностью заболевания.

## 📐 1. Математическая модель (v1.0.0-experimental)

Модель объединяет статическую оценку анкетных факторов ($L_{\text{stat}}$) и динамическое отклонение биометрии от персональной базовой линии ($L_{\text{dyn}}$):

$$L(t) = L_{\text{stat}} + c(t) \cdot L_{\text{dyn}}(t)$$

$$r^*(t) = \frac{1}{1 + e^{-L(t)}}$$

Дискретное сглаживание во времени ($\tau = 5$ мин, $\Delta t = 1$ мин, $\alpha = 1 - e^{-\Delta t / \tau} \approx 0.18127$):

$$r_{k+1} = r_k + \alpha (r^*_k - r_k)$$

$$I(t) = 100 \cdot r(t)$$

### 1.1. Статическая часть ($L_{\text{stat}}$)

$$L_{\text{stat}} = \beta_0 + \beta_1 A + \beta_2 B + \beta_3 S + \beta_4 F + \beta_5 Y - \beta_6 P$$

- **$A = (\text{age} - 40) / 10$** — нормализованный возраст ($\beta_1 = 0.50$)
- **$B = (\text{BMI} - 25) / 5$** — нормализованный ИМТ ($\beta_2 = 0.25$, $\text{BMI} = \text{weight} / \text{height}^2$)
- **$S \in \{0, 1\}$** — курение ($\beta_3 = 0.70$)
- **$F \in \{0, 1\}$** — семейный анамнез ССЗ ($\beta_4 = 0.40$)
- **$Y \in \{0, 1, 2\}$** — уровень стресса ($\beta_5 = 0.15$)
- **$P \in \{0, 1, 2\}$** — физ. активность ($\beta_6 = 0.30$, вычитается!)
- **$\beta_0 = -2.0$** — свободный член молодого здорового профиля.

### 1.2. Динамическая часть ($L_{\text{dyn}}$)

$$L_{\text{dyn}} = \beta_{\text{HR}} \Delta HR + \beta_{\text{HRV}} z_{\text{HRV}} + \beta_{\text{SpO}_2} s_{\text{SpO}_2} + \beta_{\text{ARR}} s_{\text{ARR}}$$

- **$\Delta HR = \operatorname{clip}(HR - HR_0, 0, 40)$** ($\beta_{\text{HR}} = 0.0077$, Zhang et al., CMAJ 2016)
- **$z_{\text{HRV}} = \operatorname{clip}\left(\frac{\ln(SDNN_0) - \ln(SDNN)}{\sigma_{\text{HRV}}}, 0, 3\right)$** ($\beta_{\text{HRV}} = 0.385$, Tsuji et al., Circ 1996)
- **$s_{\text{SpO}_2}$** — категориальная шкала NEWS2:
  - $\ge 96\% \implies 0$
  - $94 - 95\% \implies 1$
  - $92 - 93\% \implies 2$
  - $\le 91\% \implies 3$ ($\beta_{\text{SpO}_2} = 0.30$)
- **$s_{\text{ARR}} = \operatorname{clip}(10 \cdot p_{\text{irr}}, 0, 3)$** ($\beta_{\text{ARR}} = 0.60$, $p_{\text{irr}}$ при пороге $20\%$ отклонения RR)

### 1.3. Контроль качества данных ($c$)

$$c_q = \frac{1}{4}\sum_{j=1}^{4} q_j, \qquad c_{\text{base}} = \min\left(1, \frac{\text{days}}{7}\right), \qquad c = c_q \cdot c_{\text{base}}$$

- При **$c < 0.5$** расчет маркируется как **«Недостаточно данных для расчета»**, а тревоги блокируются.

### 1.4. Машина состояний тревог (Alert Engine)

Тревога срабатывает **только** при одновременном выполнении условий:
1. $I(t) \ge 40$ (красная зона)
2. Условие сохраняется **5 последовательных минут**
3. Полнота данных **$c \ge 0.5$**
4. Предыдущий базовый уровень был **ниже 30** (гистерезис).

## 🚀 4. Запуск приложения

Для работы Web Bluetooth API требуется запуск через защищенный контекст (`localhost` или `https`):

```bash
# Через Node.js:
npx serve .

# Либо через Python:
python -m http.server 8000
```

Откройте в Google Chrome или Microsoft Edge: **`http://localhost:8000`**
